# Realtime API Agents Demo — Short README

A minimal Next.js demo showcasing advanced voice-agent patterns using the OpenAI Realtime API and the OpenAI Agents SDK.

Quickstart
- Requirements: Node 18+, an OpenAI API key
- Setup: cp .env.sample .env and set OPENAI_API_KEY
- Install: npm i
- Run: npm run dev, then open http://localhost:3000

Notes
- Use the Scenario dropdown to switch between example agent configurations.
- For full documentation, screenshots, and deeper explanations, see README.md.
