# Realtime API Agents – Quick Start

A tiny reference for running the demo voice & chat agents that showcase the OpenAI Realtime API together with the Agents SDK.

1. `npm install`
2. Copy `.env.sample` to `.env` and set `OPENAI_API_KEY=<your-key>`
3. `npm run dev` then open http://localhost:3000

Use the **Scenario** dropdown in the UI to explore the three ready-made agent sets:
• Chat-Supervisor
• Sequential Handoff
• Customer Service Retail

That’s it — have fun hacking!  
(If you need the full, in-depth walkthrough check `docs/README_FULL.md`.)
