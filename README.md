# OpenAI Realtime Agents – Quick Start 🚀

Play with multi-agent voice experiences powered by the **OpenAI Realtime API** and **Next.js**.

```
# 1. Install deps
npm install

# 2. Add your OpenAI key (copy .env.sample → .env)

# 3. Run the demo
npm run dev
```

Open http://localhost:3000 and pick a scenario from the dropdown (e.g. *chatSupervisor* or *customerServiceRetail*). Speak or type – the browser audio streams to the Realtime API and you can watch events arrive live in the right-hand panel.

Need the full deep-dive docs, diagrams and tips? See `docs/DETAILED_README.md`.
