# Realtime API Agents Demo (Short Version)

A tiny Next.js + TypeScript web app that demonstrates how to build multi-agent voice experiences with the OpenAI Realtime API and the OpenAI Agents SDK.

Key points:
1. Live, low-latency voice chat powered by the Realtime API.
2. Multiple specialised agents that can hand off work to each other.
3. Everything wired together in a single React component: `src/app/App.tsx`.

## Quick start
1. `npm install`
2. Copy `.env.sample` → `.env` and add your `OPENAI_API_KEY`.
3. `npm run dev` then open http://localhost:3000

Use the “Scenario” dropdown in the UI to switch between example agent configurations.
