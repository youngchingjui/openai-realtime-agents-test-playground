# Realtime API Agents Demo (Short Version)

This repo is a **minimal Next.js example** that shows how to build a voice-first, multi-agent experience with the OpenAI **Realtime API** and **Agents SDK**.

Highlights
- Runs completely in the browser – no separate backend required
- Ships with a few plug-and-play agent scenarios (chat supervisor, sequential hand-off, etc.)
- Uses React + TypeScript + Tailwind for the UI

## Quick start
1. `npm install`
2. Copy `.env.sample` to `.env` and add your `OPENAI_API_KEY`
3. `npm run dev`
4. Browse to **http://localhost:3000** and pick a scenario from the drop-down.

That’s it – you now have a realtime, talking agent!
