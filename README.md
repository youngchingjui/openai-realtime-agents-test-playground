# Realtime API ‑ Agents Demo (Short Version)

A minimal Next.js + TypeScript web app that demonstrates how to build spoken-conversation agents on top of the **OpenAI Realtime API** via the **OpenAI Agents SDK**.

Quick start:
1. `npm install`
2. Copy `.env.sample` to `.env` and set `OPENAI_API_KEY=<your-key>`
3. `npm run dev` then open http://localhost:3000

The UI lets you pick from a few example agent configurations (e.g. chat-supervisor, sequential hand-off) to see different architectural patterns.

Need the detailed walk-through, diagrams and screenshots? Check out `docs/README_FULL.md`.
