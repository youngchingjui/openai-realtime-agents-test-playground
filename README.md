# Realtime API Agents – Quick Start

This repo is a **minimal Next.js demo** that shows how to build voice & multi-agent experiences on top of the OpenAI **Realtime API** and **Agents SDK**.

## Running locally

1. `git clone … && cd openai-realtime-agents`
2. `npm install`
3. Copy `.env.sample` to `.env` and add your `OPENAI_API_KEY`.
4. `npm run dev` then open http://localhost:3000

That’s it – you can now pick a scenario in the dropdown and start talking to the agents.
