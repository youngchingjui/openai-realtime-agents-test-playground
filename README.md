# Realtime API Agents – Very Short README

This repo is a **Next.js + TypeScript demo** that showcases how to build voice-first, multi-agent experiences with the **OpenAI Realtime API** and the **OpenAI Agents SDK**.

Quick start:
1. `npm install`
2. Copy `.env.sample` to `.env` and add your `OPENAI_API_KEY`.
3. `npm run dev` then open http://localhost:3000
4. Use the “Scenario” dropdown to try example agent flows (chat-supervisor, sequential handoff, customer-service, etc.).

That’s it – explore the code, tweak the prompts, and build your own realtime agent!
