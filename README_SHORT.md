Realtime API Agents Demo (Short Readme)

A minimal Next.js demo showing advanced voice-agent patterns using the OpenAI Realtime API and the OpenAI Agents SDK.

Quick Start
- Requirements: Node 18+, an OpenAI API key.
- Install: npm install
- Configure: copy .env.sample to .env and set OPENAI_API_KEY
- Run: npm run dev
- Open: http://localhost:3000

Scenarios
- Defaults to the Chat Supervisor pattern.
- Use the Scenario dropdown in the UI to switch between examples.
